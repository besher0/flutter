# Coursaty image assets

Placeholder PNGs are included so the app runs. For production, replace them with exports from the Figma design.

## Export from Figma

1. Open: [Coursaty – Copy](https://www.figma.com/design/SQ4w5F4ooNVlRcUzQUYKCM/coursaty--Copy-?node-id=67-3382)
2. Select the node, then use **Export** (bottom of Design panel) or right‑click → **Export as** → PNG (1x or 2x).
